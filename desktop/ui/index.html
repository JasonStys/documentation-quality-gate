Local authoring and review

  1. Edit documents, exact logical names and policy. Add or remove the fields your team actually requires.
  2. Save changes, then analyze the saved corpus. Findings use the original CLI parsers, rules, governance and reports.
  3. Select a finding for exact source and location. Editing invalidates the result until you save and analyze again.
  4. Fix findings or deliberately accept the exact reviewed baseline with a reason. Accepted debt and unexamined entries remain visible.
  5. Export a portable corpus or the actual JSON, SARIF and HTML reports. Existing files are never overwritten.

All data stays local and plaintext under your OS account. No document scripts, repository commands, external links, accounts or telemetry run. Use authorized material. Native corpus limits: 64 documents, 1 MiB each, 8 MiB document text; 16 inert attachments, 2 MiB total. The CLI retains its separate repository/network options.
