## Installation and operating limits

Download DocumentationQuality-1.1.1-windows-x64.zip and its matching SHA256 sidecar from Releases. Extract the complete folder and launch DocumentationQuality.exe; keep every accompanying file together. No Node or Python setup is needed.

Use the individual desktop icon or in-app help. Corpus, debt and browser state are plaintext owner-local files outside the installation. Preserve existing profiles and old versions; do not delete a lock or sidecar to force startup. The two known Desktop/Start-menu icons now target 1.1.1; original shortcut bytes, the earlier installed version and its receipt were preserved.

Acceptance is a recorded debt decision, not a repair or authenticated approval. JSON and HTML retain accepted findings; SARIF contains active findings only. Unexamined debt does not prove that a finding was fixed.

One trusted OS owner and static filesystem admission are the boundary. The app is unsigned, has no reviewer login or encryption, and does not execute document code or fetch external links. Ordinary default-profile icon activation was not tested.

Use [the native application guide](../native-application.md) for supported imports, explicit saved-source analysis, Keep editing/Discard, reasoned debt and normal Exit. Preserve old program versions and protect plaintext workspace backups yourself; do not remove owner locks or sidecars to force admission. The original CLI and GitHub Action remain available with their separately documented repository/network scope.
